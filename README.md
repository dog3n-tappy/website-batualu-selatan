# Website Resmi Lembang Batualu Selatan, Tana Toraja 🏔️

Portal digital terpadu dan modern untuk Pemerintah Desa (Lembang) Batualu Selatan, Kecamatan Sangalla Selatan, Kabupaten Tana Toraja, Sulawesi Selatan.

## 🚀 Fitur Utama

1. **Beranda & Profil Demografi**:
   - Statistik kependudukan animasi (Total Warga, Laki-laki, Perempuan, Kepala Keluarga).
   - Warta berita pembangunan dan agenda kegiatan desa terintegrasi.
2. **Profil Lembang**:
   - Sejarah Batualu (*Batu A'lu*), falsafah gotong royong *Siangkaran*, visi & misi 2024–2029.
   - Bagan struktur aparatur pemerintahan dipimpin oleh Kepala Lembang **Pradyan Rizky Londong Allo**.
3. **Layanan Administrasi Mandiri**:
   - Pengajuan online: SKU, SKD, Pengantar Nikah (NA), dan SKTM.
   - **Generator Pratinjau Surat Resmi**: Otomatis menghasilkan lembar surat berkop Pemkab Tana Toraja, stempel digital, dan verifikasi QR siap cetak (*Print-Ready* @media print / Unduh PDF).
4. **Transparansi APBD 2026**:
   - Grafik donat interaktif via Chart.js dengan rincian anggaran berimbang Rp 1.505.000.000,-.
   - Tabel responsif ramah perangkat ponsel.
5. **Pusat Pengaduan Warga**:
   - Pengajuan aspirasi (opsi anonim) dengan nomor tiket acak (#LBS-2026-XXXX).
   - Pelacak status penanganan (*live tracking* berbasis localStorage).
6. **Aksesibilitas & Tampilan Visual**:
   - Palet warna *Emerald Green* khas nuansa alam asri Toraja.
   - Tombol pengalih tema Gelap/Terang (*Dark/Light Mode*).

## 🛠️ Tumpukan Teknologi (*Tech Stack*)

- **HTML5** (Semantik & SEO Friendly)
- **Tailwind CSS** (Play CDN - Cepat & Responsif)
- **Vanilla JavaScript (ES6+)** (Ringan tanpa dependensi berat)
- **Chart.js** (Visualisasi data anggaran)
- **Font Awesome 6** (Ikon antarmuka)
